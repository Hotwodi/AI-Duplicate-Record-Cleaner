Overview

AI Duplicate Record Cleaner helps you find and eliminate duplicate records across any Odoo model. Using configurable matching rules, fuzzy string comparison, phonetic algorithms, and composite field-weighted scoring, the module identifies likely duplicates, groups them intelligently, and lets you merge them in a single click — all with full audit history.

Key Features

  • Scan Jobs — Create and run duplicate scans on any model with configurable match fields and similarity thresholds.
  • Fuzzy Matching — Detect near-duplicates using fuzzy string comparison with adjustable thresholds.
  • Duplicate Groups — Automatically group duplicate records with AI confidence scores and suggested master records.
  • One-Click Merge — Merge duplicate groups into a single master record with a single click.
  • Matching Rules — Define exact, fuzzy, phonetic, or composite matching rules with field-level weights.
  • Full Audit Trail — Every merge is logged in the Merge History for complete traceability.
